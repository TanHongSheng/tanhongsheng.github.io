Game Rule

Player A
🐱 Cat + 🦁 Lion
Player B
🐶 Dog + 🐯 Tiger
  1. Each round, each player gets 2 coins.
  2. Players place coins one at a time.
  3. The starting player alternates each round.
  4. The animal with the most coins moves.
  5. If tied, the animal further behind moves.
  6. If still tied, no animal moves.
  7. When one animal reaches 12, the game ends.
  8. The player who owns the 3rd-place animal wins.
